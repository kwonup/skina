# skina 최종 외부데이터 성능 비교 방안

## 목적

이전 `.pth` 모델과 최근 `.pth` 모델을 **동일한 외부 실데이터**로 평가해 실제 일반화 성능이 개선되었는지 확인한다.

평가에는 프로젝트의 **`최종샘플데이터셋` 폴더 안에 있는 파일들을 그대로 활용**한다.

---

## 비교 대상

- 이전 모델: 기존 `.pth`
- 최근 모델: 새로 학습한 `.pth`
- 테스트 데이터: `최종샘플데이터셋/` 내부 이미지 전체

두 모델 모두 반드시 **같은 이미지, 같은 전처리, 같은 클래스 매핑** 조건에서 추론한다.

---

## 확인할 지표

아래 4개 정도만 비교하면 충분하다.

| 지표 | 의미 |
|---|---|
| Accuracy | 전체 이미지 중 맞춘 비율 |
| Macro F1 | 클래스별 성능을 균형 있게 평가 |
| Class Recall | 각 병변을 얼마나 잘 맞추는지 확인 |
| 정답 이미지 수 | 실제 외부 이미지에서 맞춘 개수 |

추가로 Confusion Matrix를 생성해 어떤 클래스에서 성능이 개선되었는지 확인한다.

---

## 평가 방법

```text
최종샘플데이터셋
        ↓
동일한 이미지 전처리
        ↓
이전 모델 추론
        ↓
Accuracy / Macro F1 / Recall 계산

최종샘플데이터셋
        ↓
동일한 이미지 전처리
        ↓
최근 모델 추론
        ↓
Accuracy / Macro F1 / Recall 계산
        ↓
두 모델 결과 비교
```

특히 아래 경우를 따로 확인하면 좋다.

```text
이전 모델: 오답
최근 모델: 정답
```

이 이미지가 몇 장인지 계산하면 실제 외부데이터 대응력이 얼마나 개선되었는지 직관적으로 보여줄 수 있다.

---

## 최종 결과표

| Model | External Accuracy | Macro F1 | 정답 수 |
|---|---:|---:|---:|
| 이전 모델 | 측정값 | 측정값 | 측정값 |
| 최근 모델 | 측정값 | 측정값 | 측정값 |
| 개선폭 | +X%p | +X | +X장 |

---

## 성능 향상 판단

최근 모델이 학습 당시 내부 Test F1은 낮아졌더라도, `최종샘플데이터셋`에서 성능이 높아졌다면 **실제 데이터에 대한 일반화 성능이 개선되었다**고 해석할 수 있다.

예시:

> 기존 모델은 내부 테스트에서는 높은 F1을 기록했지만 외부 실데이터에서 성능이 크게 하락했습니다. 외부 데이터를 반영해 재학습한 모델은 내부 F1은 낮아졌지만, 동일한 `최종샘플데이터셋` 평가에서 Accuracy와 Macro F1이 상승하여 실제 데이터에 대한 일반화 성능이 개선되었습니다.

## 최종 산출물

- Confusion Matrix 2개
- `이전 오답 → 최근 정답` 이미지 수
- 가능하면 개선된 대표 이미지 몇 장
